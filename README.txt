TREINO MAX — PRIMEIRA VERSÃO

O que tem:
- Criar, renomear e excluir fichas
- Adicionar e editar exercícios, séries, repetições e descanso
- Modo treino com registro de kg/reps e marcação de séries
- Cronômetro de descanso
- Histórico de sessões e recordes de carga
- Dados locais, backup JSON e importação de backup
- Cache offline por service worker

IMPORTANTE:
Para instalar como app e garantir funcionamento offline no iPhone, publique estes arquivos em um endereço HTTPS (por exemplo, GitHub Pages). Abrir o HTML diretamente pelo app Arquivos não ativa o service worker.

PASSOS NO IPHONE:
1. Abra o endereço publicado no Safari e aguarde carregar uma vez com internet.
2. Toque em Compartilhar.
3. Escolha "Adicionar à Tela de Início".
4. Ative "Abrir como app da web", se essa opção aparecer, e toque em Adicionar.
5. Abra pelo ícone criado.

DADOS:
As fichas e histórico são guardados no armazenamento local do navegador/aplicativo neste aparelho. Use Mais > Exportar backup periodicamente. Limpar os dados do site pode apagar os registros.

Esta é uma versão inicial offline-first, sem conta, sincronização em nuvem ou publicação na App Store.
